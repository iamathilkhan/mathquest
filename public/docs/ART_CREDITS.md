# MathQuest Art Credits

All committed art in `public/art/` — 33 slots covering scenes, characters, and one
illustration plate per realm — is **deterministic pixel-art generated offline by
`scripts/art-process.ts` using `sharp`**. It is not AI-generated: the free
Pollinations image service was unavailable during development, so the script draws
themed placeholders instead of fetching real AI images.

### Regenerating as real AI art (when Pollinations is available)

1. `npm run art:gen` — fetches raw images into `art-src/` (git-ignored) from the free
   Pollinations image service, spacing requests >= 16 s.
2. `npm run art:process` — processes any `art-src/{slot}.png` with `sharp`
   (downscale, palette-quantise, nearest-neighbour upscale) into `public/art/`, and
   generates a deterministic placeholder for any slot still missing a raw file.

No image generation API is ever called at runtime — only this offline script does.

### Honesty on screen

The plate caption on the PICTURE tab reads **"Illustration generated by script;
diagram drawn by code."** so a reviewer can tell the current plates are
script-generated, not AI. If real AI art is generated via `npm run art:gen`, update
that caption (in `components/lesson/LearnView.tsx`) to disclose AI generation.

### What is always code-drawn (never raster art)

Diagrams — fraction bars, number lines, area grids, and ratio tables — are drawn by
code as crisp-edge SVG; numbers and labels are real HTML/SVG, never baked into raster
art. Icons, panels, buttons, and bars are code-drawn. No reference-board image or any
cropped portion of it is used as an application asset.

### Fonts

Pixelify Sans and Atkinson Hyperlegible via `next/font/google` (SIL Open Font License).
