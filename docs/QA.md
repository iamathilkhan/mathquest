# Manual QA Checklist

Complete on a laptop and phone. Mark each item only after observing it. Browser automation is not a substitute for this manual pass.

## Laptop

- [ ] 1. Landing scene, title, tagline, and settings entry.
- [ ] 2. Start Quest with no prior save opens optional name dialog.
- [ ] 3. Start Quest with a save asks for reset confirmation.
- [ ] 4. Continue appears only when a save exists.
- [ ] 5. How to Play modal opens and closes by keyboard.
- [ ] 6. Grade 5 card has curriculum topics and selects Grade 5.
- [ ] 7. Grade 6 card has curriculum topics and selects Grade 6.
- [ ] 8. Map shows all six realms and highlights the selected grade.
- [ ] 9. Other-grade realms show the grade-switch lock reason.
- [ ] 10. Change quest preserves both grades' progress.
- [ ] 11. Realm view shows stages, Guardian, rewards, and progress.
- [ ] 12. Locked stages cannot be entered directly.
- [ ] 13. First encounter opens the lesson; Skip lesson enters battle.
- [ ] 14. READ idea page shows hook, big idea, vocabulary.
- [ ] 15. Worked-example stepper reveals one step at a time.
- [ ] 16. Common-mistakes and real-world pages render.
- [ ] 17. GOT IT marks the lesson complete and opens PICTURE.
- [ ] 18. Picture view shows source tag, art fallback or plate, SVG diagram, caption.
- [ ] 19. Video Play starts only after a gesture; Pause resumes at the next sentence.
- [ ] 20. Video keyboard arrows, Space, captions, speed, and scene dots work.
- [ ] 21. Battle answer labels A-D and keyboard A-D/1-4 select matching answers.
- [ ] 22. Hint, shield, and 50/50 work and are disabled when unavailable.
- [ ] 23. Feedback shows result, exact check, explanation, and picked-option why.
- [ ] 24. Boss phase changes show phase number and taunt.
- [ ] 25. Results show X of Y score, accuracy, badge, and realm progress.
- [ ] 26. Retreat includes remedial answers with explanations.
- [ ] 27. Profile, journal, adaptive tier/mastery, and badge hints render.
- [ ] 28. Settings toggles persist, Music is hidden when feature disabled, reset confirms.
- [ ] 29. Readable mode and all reduced-motion settings visibly change behavior.
- [ ] 30. Offline banner appears offline; refresh mid-battle restores the question.

## Phone

Repeat the full walkthrough at 360×640 and 390×844. Check safe-area navigation, no horizontal overflow, 2×2 answer buttons of at least 56px, a compact arena no taller than 28vh, and that bottom navigation is hidden during active battle but appears on results.
